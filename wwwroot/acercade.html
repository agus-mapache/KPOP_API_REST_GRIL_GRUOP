Acerca de la API K-POP Girl Group

Esta es una API REST que proporciona información sobre grupos y miembros del K-POP. Es una herramienta útil para desarrolladores que quieren integrar datos de K-POP en sus aplicaciones.

Quien soy?

Soy Agustina Barbaresi, una desarrolladora y analista de sistemas apasionada por el K-POP y el desarrollo backend y frontend. Esta API es el resultado de mi interés en combinar estas dos áreas y crear una herramienta útil para la comunidad de fans de K-POP.
Mi objetivo es seguir mejorando esta API y agregar más funcionalidades en el futuro, como la posibilidad de buscar por género, año de debut, y más, Si tienes añgun interes en colaborar o tienes sugerencias, no dudes en contactarme.

Porque hice esto?

Esta API fue creada con el objetivo de combinar las dos cosas que me apacionan el codigo y los grupos de KPOP, y de esta manera poder compartir mi conocimiento y pasión con otros desarrolladores y fans del K-POP. Espero que esta API sea útil para aquellos que quieran explorar y aprender más sobre el mundo del K-POP.

Aspectos técnicos

Esta API fue construida con C# y .NET para una respuesta ultra rápida, tambien se utilizo Dapper y para la base de datos MySQL. Para acceso a Datos se realiza una consulta directa de grupos y artistas con visualización de imágenes y perfiles. Teniendo una integración con JSON para uan navegación directa a los endpoints de la API haciendo clic en los perfiles.
