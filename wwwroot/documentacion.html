Documentación

Introducción

Esta documentación te ayudará a familiarizarte con los recursos de la API KPOP GIRL GROUP y te mostrará cómo realizar diferentes consultas para que puedas aprender de una manera mas divertida con tus Idols femeninas favoritas.

REST

URL Base: https://kpopapirestgrilgruop-production.up.railway.app/api

La URL Base y Artistas contiene información sobre todos los Grupos de la API disponibles. Todas las solicitudes son GET y devuelven datos en json.

                    GET https://kpopapirestgrilgruop-production.up.railway.app/api
                    [
                        {
                            "Grupo": "https://kpopapirestgrilgruop-production.up.railway.app/api/groups",
                            "Artistas": "https://kpopapirestgrilgruop-production.up.railway.app/api/artists"
                        }
                    ]

Grupos

Schema Grupos

Hay un total de 4 grupos en la API.

Llave Tipo Descripción
id entero La identificación única del grupo en la base de datos.
name cadena El nombre del grupo (ej. IVE, BLACKPINK, TWICE).
agency cadena La agencia de entretenimiento a la que pertenece el grupo.
imageUrl cadena (url) Enlace a la imagen representativa del grupo. Todas las imágenes son URLs externas que apuntan a la fotografía oficial.

Artistas

Schema Artistas

Hay un total de 33 artistas en la API.

Llave Tipo Descripción
id entero La identificación única de la integrante en la base de datos.
name cadena El nombre artístico de la integrante (ej. Yujin, Jennie, Nayeon).
role cadena El rol o posición de la integrante dentro del grupo (ej. Líder / Vocalista, Rapera Principal).
groupId entero El identificador único del grupo al que pertenece la integrante (clave foránea que conecta con la tabla de grupos).
imageUrl cadena (url) Enlace a la imagen representativa de la integrante. Todas las imágenes son URLs externas que apuntan a la fotografía oficial.
